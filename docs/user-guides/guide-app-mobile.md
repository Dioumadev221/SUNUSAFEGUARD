# Guide d'utilisation — application Sunu

Sunu vous informe et vous oriente vers des personnes qui peuvent vous aider. Gratuit, sans compte, sans nom.
Sunu ne remplace pas un·e professionnel·le et ne prévient personne à votre place.

## Poser une question
1. Touchez **Assistant** en haut, ou **Parler à l'assistant** sur l'accueil.
2. **Pour parler** : choisissez *Je parle : Français* ou *Wolof*, touchez le micro, parlez, puis touchez à nouveau.
   Le texte reconnu apparaît dans le champ : relisez-le, corrigez si besoin, puis envoyez.
3. **Pour écrire** : tapez votre question dans le champ en bas et envoyez.
4. Sous chaque réponse : **Être orientée** (structures d'aide), **Réécouter** (lecture à voix haute), **Autre question**.

Si vous êtes en danger, des numéros d'urgence s'affichent : touchez un numéro pour appeler.

## Trouver une structure
Onglet **Trouver de l'aide** : choisissez la région, le département et le type d'aide.
Sur une fiche : **Appeler** (votre numéro s'affiche comme pour tout appel) ou **Être rappelée**.

## Être rappelée
L'app vous montre ce qui sera transmis. Vous choisissez de donner, ou non, un moyen de vous recontacter, puis vous donnez votre accord.
Vous recevez un **code de suivi** (SSG-…). L'état de la demande s'affiche dans **Mes demandes**.

## Sortir rapidement
Touchez **Sortir** (en rouge, en haut) : la conversation s'efface et une calculatrice s'affiche.
Pour revenir : tapez votre code puis **=** (1234 au départ, modifiable dans *Mes demandes*).
Ce mode cache l'écran, mais l'app reste visible dans la liste des applications du téléphone.

## Effacer toute trace
Dans **Mes demandes** → **Effacer toute trace** : conversation, codes, réglages et annuaire enregistré sont supprimés du téléphone.
Une demande déjà envoyée reste chez la structure : l'effacement ne l'annule pas.

## Confidentialité
Vos conversations ne sont pas stockées sur nos serveurs par défaut. Les messages vocaux sont transcrits puis oubliés.
